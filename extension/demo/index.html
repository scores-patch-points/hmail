Why this matters

Without sealing, the site stores and can read what you wrote. Sealed, the site stores ciphertext; only people holding the circle key see the message. The lens flips the page between the two views so you can see the difference. Revealed text sits in a closed shadow root, which the site's scripts can't read into.
